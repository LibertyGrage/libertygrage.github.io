What you need

The pack is a set of plugins that sit on top of a few well-known community mods. Those mods are not included: download each one from its author's page below. Install them first, check that the game starts with them, then add the pack (install guide).

The game

Grand Theft Auto IV: The Complete Edition, version 1.2.0.59, on Windows 10 or 11, from Steam or the Rockstar Games Launcher. Older or downgraded versions (1.0.8.0, 1.0.7.0) don't work. Which GTA IV do I have?

Why exact versions? The pack works hand in hand with the trainer and the weapon wheel, so it checks their version when the game starts. With any other version it leaves them alone and switches the matching features off, rather than risk a crash. If a newer version is out, get the one listed here from the mod page's Files tab (under Old files), until we release an update for it.

Included in the pack

  • Tandem T6 and Roadster X, our own add-on cars, as optional folders in the zip. They're also released on their own pages, and work with or without the pack.

Not needed, and best left out at first

Big overhauls that replace the same game files or hook the same trainer can clash with the pack. For your first run, start from the required mods only, then add the recommended ones. The wiki's FAQ lists known clashes.
