Beta testing on Windows

Thank you for testing. A beta build is how we find out whether what works in our own game also works on your PC. One full pass takes about two hours. When you're done, send it with the Windows test report form in the issue tracker; file each problem you found as its own bug or crash report too.

Before you start

  • A PC with Windows 10 or 11 and GTA IV: The Complete Edition 1.2.0.59 from Steam or the Rockstar Games Launcher. (Which GTA IV do I have?)
  • Ideally a game with no other mods, so a problem can only come from the pack or its requirements. If you already mod your game, back up the whole GTA IV folder and your saves first.
  • A save that is past the first island, so there's something to drive around in.

Write down as you go: the time each step took, anything in the docs that confused you, and the exact text of any error.

The checklist

1. Your setup

  1. Note your store (Steam or Rockstar Games Launcher) and Windows version.
  2. Check that GTAIV.exe says 1.2.0.59 (right-click > Properties > Details).
  3. Get its fingerprint: in the GTA IV folder, click the address bar, type cmd, press Enter, then run certutil -hashfile GTAIV.exe SHA256 and copy the long number into your report.

2. Requirements only

  1. Install the required mods with the install guide, step 1, but not the pack yet.
  2. Start the game, load your save, open the trainer, open the weapon wheel, drive for five minutes.
  3. Note your frame rate in one spot you'll come back to (the Steam overlay or any FPS counter shows it).

3. The pack

  1. Install the pack with the install guide, step 2, including Tandem T6 from the zip's Optional folder.
  2. Start the game and load your save. Note how long the first start takes and whether the "ready, restart once" line appears; then quit and start again.
  3. Open plugins\ and check the pack's .log files: does each one end by saying it is ready? Copy any line that says a check failed.
  4. Check your frame rate at the same spot as before.

4. Play

Tick off what works, and note what doesn't:

  1. The trainer's menu shows the pack's pages, and the selected line is marked.
  2. The HUD card shows next to the radar; aim at a police officer, a gang member and a civilian: the reticle changes colour.
  3. Chauffeur: set a waypoint and start a ride. Stop it halfway and take the wheel.
  4. Drive through Algonquin for ten minutes; start a fight on a busy street and see whether traffic clears.
  5. Quick settings: turn the seat belt on, crash into something hard, and check you stay in the car.
  6. Spawn two bodyguards with the trainer, get into a car, and check they get in too.
  7. Turn on police and arrests, start a gang fight near officers, and watch them respond.
  8. Weapon wheel: hold the button for the wheel, tap it to holster.
  9. Episode weapons: open the weapon wheel and pick an episode gun; fire it (does it make its own sound?); try a grenade, then the parachute from a tall building.
  10. Modes: switch to Quiet Drive, then Kids Drive, then back to Career from the menu.
  11. Cars: spawn Tandem T6 and Roadster X from the garage and drive each one for a few minutes.
  12. Play one story mission start to finish.
  13. Keep playing free roam for at least 30 minutes in total.

Where things are: on a controller, RB + X opens the trainer (F11 on the keyboard); the pack's Quick Settings are the first row of its menu, or hold Select. Start twice opens the garage. Modes are Career, Quiet Drive and Kids Drive; the handling presets are Balanced Road, Chill - Normal Handling, Chaos 1 - Heavy and Fast and Chaos 2 - Maximum; traffic is Light, Normal, Busy or Off.

5. Quit and come back

  1. Quit to Windows from the game's menu. Did it close cleanly, without a crash message?
  2. Start the game again and load your save. Is everything as you left it?

6. Uninstall

  1. Remove the pack with the install guide's Uninstall steps, starting with [Data] Remove=1. Check that update\ holds nothing of the pack's afterwards.
  2. Start the game and load your save. Does it play like before the pack?

With the recommended mods

If you can, run sections 3 and 4 a second time with the recommended mods installed too, and note which ones you used.

If you have both stores

If you own the game on both Steam and the Rockstar Games Launcher, or can borrow the other one, repeat sections 1 and 3 on the other copy. We especially want the GTAIV.exe fingerprint from a Rockstar Games Launcher copy.

Sending your results

Use the Windows test report form: it holds this checklist, so you can paste your notes into it. Attach the pack's .log files and ScriptHook.log. For anything that went wrong, also open a bug or crash report (how), so each problem gets its own fix.
