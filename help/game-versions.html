Which GTA IV do I have?

The pack works with one version of the game: Grand Theft Auto IV: The Complete Edition, version 1.2.0.59 for PC, bought on Steam or in the Rockstar Games Launcher. That is the version both stores install and keep up to date today.

The names you'll see

NameWhat it isWorks with the pack?
The Complete Edition (CE)The PC release sold since March 2020: GTA IV plus both episodes (The Lost and Damned, The Ballad of Gay Tony) in one game. Steam and the Rockstar Games Launcher both sell it.Yes, at version 1.2.0.59

Check your version

  1. Open your GTA IV folder (below).
  2. Right-click GTAIV.exe and choose Properties, then the Details tab.
  3. File version should read 1.2.0.59.

If it shows 1.0.8.0 or 1.0.7.0, your copy was downgraded. Steam can put the current version back: in your library, right-click the game, then Properties > Installed Files > Verify integrity of game files. Back up your mods first, because the downgrade's files will be replaced.

Find your GTA IV folder

It is the folder with GTAIV.exe in it.

  • Steam: in your library, right-click Grand Theft Auto IV: The Complete Edition, then Manage > Browse local files, and open the GTAIV folder inside. Usually C:\Program Files (x86)\Steam\steamapps\common\Grand Theft Auto IV\GTAIV.
  • Rockstar Games Launcher: open the launcher's Settings, pick the game under My installed games, and use the button that opens its install folder. Then look for the folder that holds GTAIV.exe.

Steam or Rockstar Games Launcher?

Both are the same game at the same version, and the pack installs the same way in both. The Steam copy also starts through the Rockstar Games Launcher. If something behaves differently between the two, please report it: only the Steam copy has been tested so far.
