Installing Liberty City Pack

Installing takes about twenty minutes the first time, most of it for the required mods. The pack itself is one folder you copy into the game, plus one restart. Nothing in the game's own files is changed: the pack only adds files to plugins\ and to FusionFix's update\ folder.

Before you start

  1. Check that you have GTA IV: The Complete Edition 1.2.0.59 (how to check).
  2. Back up:
    • your saves: Documents\Rockstar Games\GTA IV
    • your GTA IV folder, or at least plugins\, update\ and any trainer files in it.
  3. Find your GTA IV folder: the one with GTAIV.exe in it (Steam and Rockstar Games Launcher).

Step 1: the required mods

Install each mod in REQUIREMENTS by following its own readme, in this order:

  1. FusionFix 5.1.2. Start the game once and check that it still reaches the main menu. Close it.
  2. ScriptHook 0.5.1 with the Complete Edition hook fix.
  3. Liberty's Legacy 2.4.1. Start the game, load a save and open the trainer (its readme lists the key).
  4. Liberty Loadout 0.18.0. In game, open the weapon wheel once.

If the game doesn't reach the main menu at any point, undo the last mod and check its readme before going on. It's much easier to find a problem now than after the pack is in.

Step 2: the pack

  1. Download LibertyCityPack-<version>.zip from the download section and unzip it. To check the download, compare the files with SHA256SUMS.txt.
  2. Open the zip's Game Folder and copy its plugins folder into your GTA IV folder. Merge it with the plugins folder that is already there. You don't need to replace any existing file.
  3. Make the one change in Liberty Loadout's settings (below).
  4. Optional, our cars: for each car you want, open Optional\<car>\Game Folder in the zip and copy its plugins and update folders into your GTA IV folder the same way. Don't paste any data lines: the pack adds them for you on the next start. The car's own README.txt describes pasting them by hand for people who install the car without the pack; skip that step.
  5. Start the game. On this first start the pack builds the episode-weapon data from the episodes in your own copy of the game (about a second; nothing is downloaded), and adds the data lines for any of our cars you installed. About five seconds into the game a line says it's ready: quit and start the game once more.
  6. From the second start on, you have the episode weapons with their sounds, the parachute and character switching, and our cars in the garage.

What the first start does

  • It reads The Lost and Damned and The Ballad of Gay Tony files that come with your Complete Edition, and writes the data it makes into the update folder FusionFix uses. It never changes the game's own files.
  • If another mod already has one of those files there (a weapon mod's WeaponInfo.xml, or a waveslots.xml from Radio Restoration or a car mod), the pack adds to that file and keeps the original in update\z-LibertyEpisodes\originals\. If it can't add to it (a broken file, for example), it writes nothing, the on-screen line says another mod has the files, and plugins\LibertyEpisodes.log names the file.
  • The episode gun sounds need the game on an NTFS drive (Windows' normal format). On other drives the weapons work without their episode sounds.
  • After a game update, or if one of its files goes missing, it rebuilds by itself on the next start: then restart once more.
  • Keep FusionFix's own episode-weapons option off: EpisodicWeapons=0 in the [EPISODICCONTENT] section of its settings, which is the default. With it on, FusionFix crashes at start-up; the pack does that job itself.

One setting in Liberty Loadout

So the weapon wheel sits on the LB button (tap to holster, hold for the wheel), open plugins\LibertyLoadout.ini and change

WeaponWheelControllerButton NextWeapon

to

WeaponWheelControllerButton LB

Settings for other mods.txt in the zip says the same. Nothing else in another mod's files needs changing.

What's in the zip

LibertyCityPack-<version>/
  Game Folder/
    plugins/
      LibertyCityCore.asi     menus, chauffeur, traffic, police, crew, modes, crash guards
      CompactHUD.asi          HUD card, reticle, map, the world-loading fix
      LBInteractionCompat.asi the weapon-wheel button: tap to holster, hold for the wheel
      PedSpawnGuard.asi       the bodyguard spawn guard
      LibertyEpisodes.asi     episode weapons, the parachute, and the first-start step
      LibertyCityPack/cars/   our cars' data lines, which the first start adds for you
  Optional/
    TandemT6/                 Tandem T6, exactly as its own release
    RoadsterX/                Roadster X, exactly as its own release
  README.txt  LICENSE.txt  CREDITS.txt  CHANGELOG.txt
  Settings for other mods.txt
  manifest.json  SHA256SUMS.txt

The pack's own settings files (LibertyCityCore.ini, LibertyClownCar.ini, LibertyPedMenuGuard.ini, LibertyEpisodes.ini) are optional: without them every setting uses its default, and the menu saves your choices.

Check that it works

  • The trainer's menu shows the pack's pages.
  • The pack's logs in plugins\ (LibertyCityCore.log, CompactHUD.log, LBInteractionCompat.log, PedSpawnGuard.log) each end with a line saying it is ready. A line saying a version check failed means one of the required mods is not the listed version.
  • Controls to start with, on a controller: RB + X opens the trainer (F11 on the keyboard), Start twice opens the garage, LB is the weapon wheel.

On a Mac with CrossOver

Do the same steps inside your CrossOver bottle:

  1. In CrossOver, open the bottle's C: drive and go to the GTA IV folder, usually Program Files (x86)\Steam\steamapps\common\Grand Theft Auto IV\GTAIV.
  2. Follow the steps above in that folder.
  3. If no ASI mod loads at all, set a DLL override in the bottle's Wine configuration: dinput8 = native, builtin. FusionFix's own readme explains this.

Uninstall

  1. First undo the first-start data: open plugins\LibertyEpisodes.ini (create it if it isn't there), add `` [Data] Remove=1 ` then start the game once and quit. That removes every file the pack made in update\`, puts back any other mod's file it had added to, and takes our cars' data lines out.
  2. Delete the pack's files from plugins\: every file and folder listed in the zip's manifest.json. To remove one of our cars, delete its plugins\<car>.asi, its .ini and folder, and update\z-<car>\.
  3. The required mods stay installed and keep working without the pack. Remove them too, with their own readmes, if you want the plain game back.
  4. Keep the save backup from Before you start until you've played a little without the pack.

Problems

See the wiki's FAQ, then report it: attach the pack's .log files from plugins\ and say which store and game version you have.
