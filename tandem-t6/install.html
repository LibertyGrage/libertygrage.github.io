Installing Tandem T6

Installing takes about ten minutes. You copy two folders into the game and paste three lines into three text files. There is no installer, and nothing in the game's own common folder is changed.

Before you start

  1. Back up your GTA IV folder (or at least update/ and plugins/).
  2. Install everything in the README's requirements: FusionFix, ScriptHook and the Complete Edition hook fix. Start the game once to check that they work, then close it.
  3. Find your GTA IV folder: it is the one with GTAIV.exe in it. On Steam it is usually Steam\steamapps\common\Grand Theft Auto IV\GTAIV.

What's in the zip

TandemT6-<version>/
  Game Folder/
    plugins/
      TandemT6.asi          the car's plugin (seating, stability, stats, sounds)
      TandemT6.ini          its settings
      TandemT6/sfx/         20 sound files
    update/
      z-TandemT6/tandemt6.img       the car (model and textures)
      common/text/<language>7.gxt   the car's name and on-screen hints (7 languages)
  Data Lines/
    vehicles.ide.txt        one line for the game's vehicle list
    carcols.dat.txt         one line for the car's paint colours
    handling.dat.txt        one line for the car's handling
  README.txt  LICENSE.txt  CHANGELOG.txt  SHA256SUMS.txt  manifest.json

Install

  1. Download TandemT6-<version>.zip from the download section and unzip it. If you want to check the download, compare the files with SHA256SUMS.txt.
  2. Open the zip's Game Folder and copy its two folders, plugins and update, into your GTA IV folder. Merge them with the folders that are already there. You don't need to replace any existing file.
  3. Add the three data lines. In your GTA IV folder, open update\common\data: Never edit the files in common\data itself. Data Lines. Each .txt file says where its line goes:
    • If vehicles.ide, carcols.dat or handling.dat is missing there, copy it in from common\data first.
    • If another add-on car already put these files there, keep them and add our lines to them.
    • Open each file in a plain text editor (Notepad works) and paste the line from the matching .txt file in
      • vehicles.ide: inside the cars section, just before that section's end line
      • carcols.dat: inside the car3 section, just before that section's end line
      • handling.dat: on its own line among the other car rows
    • Paste the lines exactly as they are (they contain tabs) and save as plain text.
  4. Start the game and spawn tandemt6 with your trainer. With Liberty's Legacy, add tandemt6 on its own line to the trainer's add-on car list (Liberty's Legacy\Lists\addon_vehicle_models.txt in your GTA IV folder), and the car shows up in its add-on vehicles menu.
  5. Get in. A short hint shows the controls, and the stats card shows your best times (controls).

On a Mac with CrossOver

Do the same steps inside your CrossOver bottle:

  1. In CrossOver, open the bottle's C: drive and go to the GTA IV folder, usually Program Files (x86)\Steam\steamapps\common\Grand Theft Auto IV\GTAIV.
  2. Follow steps 1 to 5 above in that folder.
  3. If no ASI mod loads at all, set a DLL override in the bottle's Wine configuration: dinput8 = native, builtin. FusionFix's own readme explains this.

Uninstall

  1. Delete these from your GTA IV folder: japanese7.gxt, russian7.gxt and spanish7.gxt
    • plugins\TandemT6.asi, plugins\TandemT6.ini and the folder plugins\TandemT6\
    • the folder update\z-TandemT6\
    • the seven text files update\common\text\american7.gxt, french7.gxt, german7.gxt, italian7.gxt,
  2. Remove the three Tandem T6 lines from vehicles.ide, carcols.dat and handling.dat in update\common\data. If you copied those files there only for this mod and no other mod uses them, you can delete them instead.
  3. If you added tandemt6 to your trainer's add-on list, remove that line too.
  4. Before you uninstall, don't leave the car in a safehouse garage. Get out of it somewhere else, then save.

Troubleshooting

ProblemFix
The trainer can't spawn tandemt6, or the game says the model isn't foundCheck that update\z-TandemT6\tandemt6.img is in place and that the vehicles.ide line is inside the cars section of update\common\data\vehicles.ide.
The game crashes while loading after you added the linesA data line is broken or in the wrong section. Paste it again from Data Lines, with its tabs. Make sure the TANDEMT6 row is in handling.dat, because the vehicles.ide line refers to it.
The car's name shows as TANDEMT6 or nothing at allThe text files update\common\text\*7.gxt are missing, or another mod replaced them (see Known issues in the README).
No stats, no hint, no rear-seat boarding, no custom soundsThe plugin didn't load. Check that ScriptHook (ScriptHook.dll) and aCompleteEditionHook.asi are installed. plugins\TandemT6.log says what loaded.
No motor soundCheck that the 20 files are in plugins\TandemT6\sfx\, that [Sound] Enabled=1 in plugins\TandemT6.ini, and that the game's SFX volume isn't at zero.
The horn is silentThat's expected: see Known issues in the README.
K or the controller chord does nothingThe game window must have focus, and the keys are ignored while a trainer menu is open. Check [Keys] and [Pad] in plugins\TandemT6.ini if you remapped them.
The stats overlap another HUD modMove them with [Hud] X, Y, CardX and CardY in plugins\TandemT6.ini.
On a Mac, no mod loads at allSet the dinput8 DLL override (see "On a Mac with CrossOver" above).

When you report a problem, attach plugins\TandemT6.log and say which game version and other mods you use (report a bug).
