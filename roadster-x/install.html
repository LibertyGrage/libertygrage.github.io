Installing Roadster X

Before you start

  1. Back up your GTA IV folder (or at least update\ and plugins\).
  2. Install the requirements from the README: FusionFix, then ScriptHook with aCompleteEditionHook.asi. Start the game once to check that they work.

What's in the zip

RoadsterX-<version>\
  Game Folder\
    plugins\RoadsterX.asi          the car's systems (thrusters, flight, wing, panel)
    plugins\RoadsterX.ini          every setting, one comment per line
    plugins\RoadsterX\sfx\*.wav    the car's sounds
    update\z-RoadsterX\roadsterx.img        the model and its textures
    update\common\text\<language>8.gxt      the car's name and on-screen text (7 languages)
  Data Lines\
    vehicles.ide.txt  carcols.dat.txt  handling.dat.txt   one line each, to paste
  README.txt  LICENSE.txt  CHANGELOG.txt

Install

  1. Download RoadsterX-<version>.zip from the download section and unzip it.
  2. Open its Game Folder and copy the two folders inside it, plugins and update, into your GTA IV folder (the one with GTAIV.exe). Let them merge with the folders that are already there.
  3. Add the three lines from Data Lines to the game's data files: missing there, copy it in first from common\data. Never edit the files in common\data itself. with a plain text editor such as Notepad, and save.
    • In your GTA IV folder, open update\common\data. If vehicles.ide, carcols.dat or handling.dat is
    • Open each .txt in Data Lines. It says which file the line goes into and where. Paste the line there
  4. Start the game and spawn the car by its model name, roadsterx, with your trainer. Liberty's Legacy shows add-on cars from Liberty's Legacy\Lists\addon_vehicle_models.txt: add the line roadsterx there.
  5. Get in. The systems switch on and the controls appear on screen.

On a Mac with CrossOver

Do the same inside your CrossOver bottle:

  1. In CrossOver, open the bottle's C: drive and go to the GTA IV folder, usually Program Files (x86)\Steam\steamapps\common\Grand Theft Auto IV\GTAIV.
  2. Follow steps 1 to 5 above in that folder.
  3. If no ASI mod loads at all, set a DLL override in the bottle's Wine configuration: dinput8 = native, builtin (FusionFix's own readme explains this).

Uninstall

  1. Delete these from your GTA IV folder: japanese8, russian8 and spanish8. Check first that no other mod uses them.
    • plugins\RoadsterX.asi, plugins\RoadsterX.ini and the folder plugins\RoadsterX\
    • the folder update\z-RoadsterX\
    • the seven Roadster X text files update\common\text\*8.gxt: american8, french8, german8, italian8,
  2. Remove the three Roadster X lines from update\common\data\vehicles.ide, carcols.dat and handling.dat. If you copied those files in only for this mod, you can delete them instead.

Troubleshooting

ProblemFix
The car doesn't spawn, or its name shows wrongCheck the vehicles.ide and carcols.dat lines, and that update\z-RoadsterX\roadsterx.img is in place.
It drives, but jumping, flying and the thrusters do nothingScriptHook isn't loading: check ScriptHook.dll and aCompleteEditionHook.asi in the game folder. plugins\RoadsterX.log says what loaded.
No ASI mod loads at all (Mac)Set the dinput8 DLL override described above.
"Roadster X systems are OFF"Turn them on: hold LB and click R3 (keyboard: K).
The on-screen panel hides somethingHide it in plugins\RoadsterX.ini with [Hud] Show=0, or move it with PanelX and PanelBottom.
Another mod's text disappeared, or the car shows no nameBoth use update\common\text\*8.gxt. Tell us which mod and we'll release a version with another text slot.
The handling feels wrongCheck that the handling.dat line went into update\common\data\handling.dat and that no other mod uses the ROADSTERX row.

When you report a problem, attach plugins\RoadsterX.log and say which game version you have.
