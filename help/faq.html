FAQ

Is it free?

Yes, always, for everyone. There may be an optional tip link; a tip unlocks nothing. See TERMS.

Which version of GTA IV do I need?

The Complete Edition, version 1.2.0.59, from Steam or the Rockstar Games Launcher. How to check.

Does it work with a downgraded game (1.0.8.0 or 1.0.7.0)?

No. The pack works with the Complete Edition's code, and on any other build it switches itself off.

Will it break my saves?

The pack doesn't edit your save files. As with any mod, back up Documents\Rockstar Games\GTA IV before you install it, and keep that backup until you're sure.

One thing is untested: removing the pack while Niko carries episode weapons in a save. Until we've tested it, put the episode weapons away and save without them before you uninstall.

Are Rockstar's episode files included?

No. The episode weapons are built on your own PC, from the episodes in your own copy of the Complete Edition, the first time the pack starts. Nothing from the game is in the download.

Does it change the story missions?

No. The features that change how the city behaves, like jam relief and gang behaviour, step back during missions.

Can I play online with it?

The Complete Edition has no online multiplayer, so the question doesn't come up.

Does it work with other mods?

Mods that only add or replace cars, textures or sounds usually work alongside it. Watch out for:

  • Other trainers or script overhauls that hook Liberty's Legacy or the same game code.
  • Overhauls that replace FusionFix's files or ship their own trainer.
  • A different Liberty's Legacy or Liberty Loadout version: the pack then switches the matching features off. See REQUIREMENTS.
  • Our own cars (Tandem T6, Roadster X) work with or without the pack.

Does it work on a Mac?

It runs in the Windows version of the game through CrossOver on a Mac, the same way it does on Windows. The install guide has the one extra step.

Steam Deck, Linux, consoles?

The pack is made for the PC game on Windows. On Steam Deck or Linux through Proton it's untested: tell us how it goes. There are no console versions.

Something doesn't work

Check the pack's .log files in plugins\: each one says whether that part started, and why not if it didn't. Then report it.
