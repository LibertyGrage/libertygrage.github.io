The pack's number: MAJOR.MINOR.PATCH

We use the same three-number style as the mods you already know: FusionFix 5.1.2, Liberty's Legacy 2.4.1, Liberty Loadout 0.18.0. Each part tells you something different.

PartExampleWhat changedWhat you do
PATCH, the last number0.1.0 → 0.1.1Fixes only. Nothing new to learn.Update over the top; your settings stay.
MINOR, the middle number0.1 → 0.2New features, or a mod added to the pack. New settings may appear and some defaults may change.Read the changelog, then update. Check whether a requirement's version changed.
MAJOR, the first number0.x → 1.0, 1.x → 2.0A big step. 1.0 is the first full release after the betas. A later major version means something you need to redo, such as a fresh install or a new requirement.Follow that version's install notes.

While the first number is 0, the pack is in its beta years: features can still move between versions, and we say so in the changelog.

Test builds: beta and RC

  • beta (0.1.0-beta.1, 0.1.0-beta.2, ...): a public test build. Expect rough edges, and please report them.
  • RC, release candidate (1.0.0-rc.1): the build we plan to call final, unless testers find a problem.
  • No label (1.0.0): the finished version.

Mod sites show the same number as this wiki, so you can always match a download to its changelog.

What every release says

Each release lists, at the top of its notes:

  • Built for: GTA IV: The Complete Edition 1.2.0.59 (Steam and Rockstar Games Launcher)
  • Needs: each required mod with its exact version
  • Includes: our own parts and their versions, for example Tandem T6 1.0.0 and Roadster X 1.0.0
  • Saves: whether the update affects saves. Most don't, and we always say when one does

How changes are listed

The changelog groups every version's changes the same way:

  • Added: new features and newly included mods
  • Changed: things that work differently now, including new defaults
  • Fixed: bugs and crashes, with a link to the report and thanks to whoever reported it
  • Removed: anything taken out, and why

Every mod the pack builds on, includes or recommends is credited in CREDITS, and a new one is credited in the changelog of the version that brings it in.
